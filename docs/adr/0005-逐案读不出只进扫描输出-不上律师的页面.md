# 逐案读不出只进扫描输出，不上律师的页面

清单页末尾那几行暗色的读不出（视图不是合法 JSON、结构不全、读取被拒、格式版本不是 2）是写给开发者的：律师照着做不了任何事，而根目录下只要有一份早先工作台写的老视图，卡片就常年顶着一行报错。裁定：逐案的读不出照旧由扫描脚本按案件隔离、照实写进输出的 `读不出`，页面一律不画；不变量 3 的「明确报错」在命令行这一层照旧成立，开发者拿扫描输出看全貌。根目录不存在或读不出的那一类不在此列，它是律师自己填的设置，和设置错误的整页指引一样照旧显示。代价是律师正在办的一案若视图坏了，会从卡片上悄悄消失，直到引擎下次写图整份重算才回来；接受，因为坏视图本来就只能靠引擎重算修好，卡片报出来律师也无从下手。

这推翻了 #10 的文案裁定：「老格式（格式版本 1）……别对它打起手」那一句是写给律师的，读者没了就收回，版本 1 与其他不认识的版本一样照实报「只认 2」。它防的那件事——对老案重新起手把归好的东西挪走——由 setup-case 自己守着：当前目录已有 `图.json` 就拒绝起手。

「经 setup-case 起手」不另立标记：有 `图视图.json` 且格式版本是 2 就是那个标记。另读工作区 `AGENTS.md` 的指针块会破不变量 1，让引擎加字段会破不变量 7。
