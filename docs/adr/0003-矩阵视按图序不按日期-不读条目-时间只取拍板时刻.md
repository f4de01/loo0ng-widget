# 矩阵视按图序排，不按日期；不读条目；时间只取引擎写的拍板时刻

最初的参考是 GitHub 贡献图那种「一天一格」的活动热力图。核实数据：`图视图.json` 节点层只有 `最近生成.时间` 与 `最近确认.时间`（拍板时刻），`时限` 是自由文本句，没有任何法律事件日；逐日动作史全在 `条目` 里，而「输出不含条目」是本仓库一条被测试守着的不变量，「要看条目才能得出的结论必须引擎先算」是 ADR-0029 的原话。裁定：矩阵视一格一节点、一列一模块、按图序排，颜色是状态，悬浮里带时间；它回答「整案走到哪」，与模块视互补。活动热力图若将来真要，得让引擎在视图里先算出按日计数，那是格式版本 3 的事。节点上显示的时间只取拍板时刻，已确认取确认、已生成取生成，不读文书文件的修改时间（卡片只读那一个文件，且 Word 里随手保存 mtime 就变）。不适用在节点层没有时间字段，不显示。
