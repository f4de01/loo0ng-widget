# 材质以透明窗上自绘卡片为底，系统模糊只作可降级的增强

律师要 Apple 桌面小组件那种透光、磨砂的样子。核实：Zebar 3.3.1 的 `transparent: true` 直通 Tauri（mac 端已开私有 API），但 CSS `backdrop-filter` 在透明窗里只模糊页面自己的内容、模糊不了桌面；真磨砂要系统材质，Zebar 自己不设（上游需求 #93 未落地），但 ACL 放行了 `core:window:allow-set-effects`，页面可以自己调 Tauri 的 `setEffects`，无人验过在这扇窗里的效果，有人反映 Win11 上 Blur / Mica 拖动缩放时性能差。裁定：底是透明窗 + 自绘圆角浅色卡片（不透明度约 90%，细描边、内高光、柔投影画在 12px 透明外边距里）；启动时试调一次 `setEffects`（Windows Acrylic、mac vibrancy），成功就把底色降到约 60% 让模糊透出来，失败一言不发停在自绘那层。状态为 proposed：Windows 上先起一个短 spike 看 Acrylic 在 Zebar 窗里行不行，结果记回本条后转 accepted；mac 实机进交付票。同时定下：圆角 18px、内边距 16px、正文 13px、最小 11px、字体栈 `-apple-system, "PingFang SC", "Segoe UI", "Microsoft YaHei"`；不做深色模式，颜色全抽成变量。
