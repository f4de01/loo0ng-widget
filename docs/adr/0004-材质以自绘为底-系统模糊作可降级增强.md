# 材质以透明窗上自绘卡片为底，系统模糊只作可降级的增强

律师要 Apple 桌面小组件那种透光、磨砂的样子。核实：Zebar 3.3.1 的 `transparent: true` 直通 Tauri（mac 端已开私有 API），但 CSS `backdrop-filter` 在透明窗里只模糊页面自己的内容、模糊不了桌面；真磨砂要系统材质，Zebar 自己不设（上游需求 #93 未落地），但 ACL 放行了 `core:window:allow-set-effects`，页面可以自己调 Tauri 的 `setEffects`。裁定：底是透明窗 + 自绘圆角浅色卡片（不透明度约 90%，细描边、内高光、柔投影画在 12px 透明外边距里）；系统模糊只在它能贴着圆角卡片的形状时才用：Windows 上不用（见下），mac 的 vibrancy 进交付票在实机看、同一条标准；用上了才把底色降到约 60% 让模糊透出来，否则停在自绘那层。色值取原型的 A 纸那套。同时定下：圆角 18px、内边距 16px、正文 13px、最小 11px、字体栈 `-apple-system, "PingFang SC", "Segoe UI", "Microsoft YaHei"`；不做深色模式，颜色全抽成变量。

Windows 上的 spike 已做（#13，`prototype/呈现` 分支，`docs/prototype-呈现.md`），据此由 proposed 转 accepted，并补三条实测结论：

- **Acrylic 行，没有性能代价。** Windows 11 的 Zebar 透明窗里 `setEffects({effects:['acrylic']})` 立刻生效，桌面透过 60% 的卡片被模糊、字可读；程序移窗、程序缩放、鼠标拖动、鼠标缩放的帧间隔均值 4.2ms、没有一帧超过 33ms，与不开效果无差。有人反映的 Blur / Mica 卡顿没有在 Acrylic 上出现。
- **Acrylic 盖的是整个窗口矩形。** 12px 透明外边距与圆角外的四个角一起被磨砂成一块方板，柔投影画在板上。这是系统材质的形状，页面改不了。裁定（看过截图后）：不接受方板。圆角卡片与透明外边距是律师要的形，比磨砂更要紧，而页面改不了系统材质的形状，所以 Windows 上不调 `setEffects`，停在 90% 自绘那层。mac 的 vibrancy 若同样盖满矩形，一样不用。
- **成功的返回值不等于看得见。** Windows 上 `setEffects` 对 `mica`、`tabbed`、带 `color` 的 `acrylic` 都返回成功，其中 mica 在这扇窗里没有任何可见变化，`blur` 返回成功但整块窗口变成深灰黑。将来哪个平台要试系统模糊，只试一种、不按「哪个成功用哪个」去探；调用抛错才算失败；不抛错但没效果的情形页面无从得知。不开效果时 90% 的自绘底单独成立、外边距干净，这是可靠的底层。

色值与 `:root` 变量表不在本条里，住原型分支的说明，#16 从那里取值。

## 2026-09-25 附注：色值改冷色调

上文「色值取原型的 A 纸那套」不再成立。呈现优化那一轮（#22）律师从参考图里取了色调方向：偏冷的浅蓝灰底、深色字，状态色收进同一个蓝色系——已确认深蓝实心、已生成中蓝半实、未生成灰空心、不适用淡灰斜线。新旧对照截图里看得到两处差别：A 纸底上进度条「未生成」那一段几乎化进底色，冷底上它是一条看得见的浅槽；状态色同一色系之后，琥珀那一圈在正常画面里是唯一的暖色，一眼就是「等你看」。报错的红棕不改：它只在出错时现身，本来就该显眼。色值在开发预览里截图给律师看过、认可之后才定（#22）。

本条其余裁定不动：透明窗上自绘卡片、不透明度 90%、系统模糊的取舍、尺度与字体栈、不做深色模式、颜色全抽成变量。这一轮顺带把「颜色全抽成变量」落成一条测试：样式表里 `:root` 之外不许出现色值字面量。

## 2026-09-25 附注二：状态从形状编码改成深浅编码

上一条附注里「颜色不是状态的唯一载体：形状先说话」（空心、半实、实心、斜线）不再成立。矩阵视重做那一轮（#24）律师照一张贡献图式格阵的参考图定：状态只用深浅说话——已确认深蓝、已生成浅蓝、未生成空白，三档都是实填；圆圈跟着改，不留一套形状给模块视，理由是同一张卡片上同一个状态只该有一种样子。代价有两处，当场定了补法：不适用不再有自己的样子，也画空白（矩阵靠悬浮概览，模块视靠那一行字变淡）；矩阵格上不再画琥珀圈（14px 的格子配 3.5px 的缝放不下，「等你看」留在悬浮概览与圆圈上）。

两档蓝换成参考图那一对饱和的蓝（深 `#2566d0`、浅 `#86acea`）：进度条、圆圈、矩阵格共用变量，只换矩阵那边会让同一页上出现两种「已确认蓝」；原来的中蓝做实填的浅档也偏深。冷色调的底与空白灰不动。进度条仍分四段，不适用那段保留斜纹：进度条回答「各有多少」，扫描脚本给的分段口径不改。
