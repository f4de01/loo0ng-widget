# 材质以透明窗上自绘卡片为底，系统模糊只作可降级的增强

律师要 Apple 桌面小组件那种透光、磨砂的样子。核实：Zebar 3.3.1 的 `transparent: true` 直通 Tauri（mac 端已开私有 API），但 CSS `backdrop-filter` 在透明窗里只模糊页面自己的内容、模糊不了桌面；真磨砂要系统材质，Zebar 自己不设（上游需求 #93 未落地），但 ACL 放行了 `core:window:allow-set-effects`，页面可以自己调 Tauri 的 `setEffects`。裁定：底是透明窗 + 自绘圆角浅色卡片（不透明度约 90%，细描边、内高光、柔投影画在 12px 透明外边距里）；启动时试调一次 `setEffects`（Windows 只试 `acrylic`、mac 试 vibrancy），成功就把底色降到约 60% 让模糊透出来，失败一言不发停在自绘那层。同时定下：圆角 18px、内边距 16px、正文 13px、最小 11px、字体栈 `-apple-system, "PingFang SC", "Segoe UI", "Microsoft YaHei"`；不做深色模式，颜色全抽成变量。

Windows 上的 spike 已做（#13，`prototype/呈现` 分支，`docs/prototype-呈现.md`），据此由 proposed 转 accepted，并补三条实测结论：

- **Acrylic 行，没有性能代价。** Windows 11 的 Zebar 透明窗里 `setEffects({effects:['acrylic']})` 立刻生效，桌面透过 60% 的卡片被模糊、字可读；程序移窗、程序缩放、鼠标拖动、鼠标缩放的帧间隔均值 4.2ms、没有一帧超过 33ms，与不开效果无差。有人反映的 Blur / Mica 卡顿没有在 Acrylic 上出现。
- **Acrylic 盖的是整个窗口矩形。** 12px 透明外边距与圆角外的四个角一起被磨砂成一块方板，柔投影画在板上。这是系统材质的形状，页面改不了。取舍：留外边距与圆角，接受角上那一小块方磨砂；不为了消掉它放弃圆角或放弃系统模糊。mac 的 vibrancy 是否同样盖满矩形，进交付票在实机看。
- **成功的返回值不等于看得见。** Windows 上 `setEffects` 对 `mica`、`tabbed`、带 `color` 的 `acrylic` 都返回成功，其中 mica 在这扇窗里没有任何可见变化，`blur` 返回成功但整块窗口变成深灰黑。所以只试 `acrylic` 一种，不按「哪个成功用哪个」去探；调用抛错才算失败、才停在自绘层；不抛错但没效果的情形页面无从得知，只能靠只试这一种把它压到最小。60% 的底只在系统模糊真在时用，不开效果时 90% 的自绘底单独成立、外边距干净。

色值与 `:root` 变量表不在本条里，住原型分支的说明，#16 从那里取值。
