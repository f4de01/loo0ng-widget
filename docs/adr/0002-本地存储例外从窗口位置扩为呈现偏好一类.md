# 本地存储的例外从「窗口位置」一项扩为「呈现偏好」一类

硬边界 2 原文把「窗口位置记在 WebView 本地存储里」定为唯一例外。呈现定形之后卡片有了两页、两种形式，律师切到矩阵视、看着某一案，下次打开理应回到那里。裁定：例外从一项扩为一类，叫**呈现偏好**，成员只有三样：窗口位置、停在哪一页哪一案、选中的形式。它的性质没变，仍不碰文件、不碰工作区、不新开任何通往引擎的写入面；扩的是类，不是边界。启动时记住的偏好总是赢，不会被「最近变动的案」之类的猜测覆盖（ADR-0001）。存储缺失、无效或不可写时回到清单页与预设位置。
