# 给律师的五分钟实验：卡片读不到文件夹时，到底是谁拦的

> 对应 [#11](https://github.com/f4de01/loo0ng-widget/issues/11)。这一页是**给人照着做、照着填**的，不是开发说明。做完把最后那张表填了发回来就行。

## 为什么要麻烦你做这个

mac 对「桌面」「文稿」「下载」这三个文件夹有一道系统级的把门。我们现在**不确定卡片有没有撞上过这道门**：

- 如果撞上过，卡片现在那句「根目录读不出，请检查路径和读取权限」就得改写成一句告诉你去哪儿开开关的话；
- 如果压根没撞上，这件事我们就不做了，省下的功夫去做别的。

你手上那台机器是唯一能回答这个问题的地方。**全程只会碰你的「下载」文件夹**，不碰案件、不改案件、不读案件里的任何东西。

## 事前三条

1. 这一趟**不要把 `~/.loo0ng/卡片设置.json` 的内容发回来**——那里面写着你的案件根目录。备份文件留在你本机就好。
2. 万一哪张截图里带出了当事人名、案号或案件文件夹名，**先裁掉再发**。
3. 任何一步跟下面写的不一样、或者你不确定，**就停下**，把卡在哪告诉我们，别硬试。停在半路不影响你办案——最后一步是把设置改回去，没走到那一步就告诉我们，我们带你改回来。

---

## 第 0 步：先拍一张开关现状（这一步本身就有用）

打开 **系统设置 → 隐私与安全性 → 文件与文件夹**，找到 **Zebar** 那一项，把它下面所有开关的样子拍一张照。

找不到 Zebar 这一项也是一个答案，照实说「列表里没有 Zebar」。

> 这一步单独就能答掉我们一直没问到的那个问题：**你到底有没有给它开过「文稿文件夹」**。

## 第 1 步：备份现在的设置

打开**终端**，整行粘贴，回车：

```sh
cp ~/.loo0ng/卡片设置.json ~/.loo0ng/卡片设置.json.bak
```

没有任何输出就是成功了。这份备份是第 5 步用来还原的。

## 第 2 步：把卡片的根目录临时指到「下载」

整行粘贴，回车：

```sh
cat > ~/.loo0ng/卡片设置.json <<'EOF'
{"根目录": ["~/Downloads"]}
EOF
```

这一步之后卡片当然看不到你的案子了——**这是故意的**，第 5 步会改回来。

## 第 3 步：重开卡片，看那一行

关掉卡片窗口，再从菜单栏的 Zebar 图标重新打开它（`Widget packs → loo0ng → 案件卡片 → 默认`；这一项是个开关，已经勾着的话先点一下关掉，再点一下打开）。

> mac 上这个菜单我们没实机看过，长相跟这里写的不一样就照你看到的点。

打开后**等五秒**，然后记三件事：

- 卡片上写的是什么（**照抄原文**，或者拍一张卡片全窗的照片）；
- 期间**有没有弹出过系统授权框**（就是那种问「Zebar 想访问你的下载文件夹」的框）；
- 如果弹了，**先别急着点**，把框上的字拍下来，然后**点「不允许」**（这一趟我们要的是被拦住的样子）。

## 第 4 步：同一件事，在终端里再跑一次

这一步是对照组：终端和卡片在系统眼里是两个不同的程序，权限也是分开算的。整行粘贴，回车：

```sh
python3 ~/.glzr/zebar/loo0ng/scan.py --根 ~/Downloads
```

把**吐出来的整段**原样复制回来（很长也没关系，里面只会有「下载」文件夹的内容，不会有案件）。这一步如果也弹授权框，同样记下来，这次**点「允许」**，然后把前后两次的输出都留着。

## 第 5 步：改回去（别漏了这一步）

整行粘贴，回车：

```sh
cp ~/.loo0ng/卡片设置.json.bak ~/.loo0ng/卡片设置.json
```

再照第 3 步重开一次卡片，确认**你的案子都回来了**。回不来就告诉我们，别自己改。

## 附：你可能看到的三种样子

**以你实际看到的为准**，跟下面对不上也照实写，不要往这三条上靠——对不上恰恰是我们最需要知道的。

| 卡片上出现 | 意味着 |
| --- | --- |
| 红底一行「根目录读不出，请检查路径和读取权限」 | 系统这道门确实拦了卡片，那句话要改写 |
| 「在办案件 0」，没有红底行 | 系统没拦，这件事不用做了 |
| 「根目录不存在」 | 路径写错了，多半是第 2 步那条命令没粘全 |
